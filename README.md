# Editor Ticker · versões

Instaladores do app "Editor Ticker" para Mac com chip Apple (M1 ou mais novo).
O código fica no repositório privado `bebb963/editor-ticker`; aqui só ficam os arquivos de instalação.

Para instalar: baixe o `Editor Ticker.dmg` da versão mais nova, abra e arraste o Editor Ticker para Aplicativos.
O app se atualiza sozinho depois disso.
